# 全民飞机大战 - 核心框架

## P2 · 免费抽奖与装备套装（2026-11-10）

当前分支：`feat/p2-equipment-free-gacha`。**全部为单机虚拟道具**，不关联真实货币或账号充值。

### 新增内容

- 装备目录共 15 件：5 件基础装备、神犬套 5 件、天蓬套 5 件。五个槽位：主武器、副武器、护甲、核心、增幅器。名称借鉴历史套装资料；属性、分级与技能效果为本项目原创。
- 装备可穿戴、单级强化至 10 级、一键升满级。收集齐套装可以一键换装，2 件套提供属性加成，5 件套在使用战机主动技能时触发额外弹幕。
- **无限金币与钻石**：UI 显示 ∞，所有抽奖免费，不会扣除资源；没有真实支付，也不依赖服务器。
- 抽奖有金币补给/钻石祈愿、单抽/十连、逐件揭晓动画、NEW 标签、重复次数和保底标记；不播放抽奖音效。
- 概率和保底（均为本项目自定，不是原版官方数据）：

| 抽奖池 | 普通 | 史诗 | 传说 | 累计保底 |
|---|---:|---:|---:|---|
| 金币补给 | 70% | 27% | 3% | 至多 10 抽出史诗及以上、30 抽出传说 |
| 钻石祈愿 | 55% | 35% | 10% | 至多 10 抽出史诗及以上、30 抽出传说 |

保底计数对两种抽奖池分别计算；抽到指定品质会重置相应计数。重复抽到的装备不消失，而是累计持有次数。

- **圆梦按钮**：一键免费获得全部 15 件装备、升至 Lv.10，并穿戴整套神犬装备。随时可以改穿天蓬套或自行混搭。
- `localStorage` 自动保留抽奖历史计数、各抽奖池保底、装备持有、强化等级和穿戴状态（仅此浏览器/站点数据，清除站点数据后会丢失）。
- `js/data/EquipmentCatalog.js` 装备配置；`js/systems/EquipmentManager.js` 背包、保底、穿戴、存档；`js/ui/CollectionUI.js` 可视化仓库和抽奖；`test_equipment.js` 装备/抽奖测试。

## P1 · 战机仓库与主动技能（2026-11-10）

在独立分支 `feat/p1-aircraft-hangar` 中开发。首版加入 4 架历史名称的战机：**歼-31、枭龙、零号执行者、哈迪斯**。四架都可免费选择，分别具有独立的生命值、速度、主武器及 Q 键主动技能。

- 大厅战机仓库：点击战机卡片选择；首次进入默认歼-31
- 主动技能：歼-31 追踪导弹、枭龙扇形弹幕、零号执行者穿透弹、哈迪斯护盾与清弹；各技能均有独立冷却
- 战斗中不能切换战机，避免借换机补血；在暂停、结算或游戏结束后可返回仓库
- 四种原创 Canvas 战机轮廓，不使用提取自手游的图片
- 技术实现：`js/data/AircraftCatalog.js` 为配置表；`js/systems/AircraftManager.js` 统一处理属性、武器、技能；`js/ui/HangarUI.js` 负责 UI
- 已有的机枪、激光炮、导弹类仍复用。P2 已加入装备、套装、升级和浏览器本地存档；宠物系统仍待后续开发。

**注意：战机名称和发行时期为怀旧参考；技能名称、数值和矢量外观均为本项目原创方案，并非腾讯原版的正式技能数据或原版素材。**

操作：大厅点击战机 → 开始游戏 → 方向键 / WASD 移动、自动攻击、**Q** 使用主动技能、Tab 切换副武器、空格炸弹、Esc 暂停；触屏也可以点击技能按钮。

本地运行：

```powershell
# 浏览器打开 http://127.0.0.1:8080
```

## 操作说明

### 键盘控制
- **Enter** - 开始游戏（在菜单界面）
- **方向键/WASD** - 控制战机移动
- **ESC** - 暂停/继续游戏
- **F3** - 切换调试模式（显示性能信息）

### 游戏状态
- **菜单** - 按 Enter 开始游戏
- **游戏中** - 控制战机躲避和射击
- **暂停** - 按 ESC 暂停/继续
- **游戏结束** - 按 Enter 返回菜单
