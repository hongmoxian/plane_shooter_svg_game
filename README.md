# 全民飞机大战 - 核心框架

## 项目概述

本项目为经典街机风格垂直卷轴飞机射击游戏的核心框架实现，完成了游戏的基础架构开发。

## 已完成功能

### 阶段一：核心框架 ✅

✅ **游戏循环和状态机**
- 固定时间步长的游戏循环（60 FPS）
- 完整的状态机系统（菜单、游戏、暂停、游戏结束）
- 性能监控和自动质量调整

✅ **基础渲染系统**
- Canvas 2D渲染器
- 背景滚动效果
- 精灵绘制系统
- HUD界面显示
- 调试信息显示（F3切换）

✅ **输入系统**
- 键盘输入处理（方向键/WASD移动）
- 鼠标和触摸支持
- 输入平滑和缓冲
- 死区处理

✅ **玩家战机基本控制**
- 8方向移动控制
- 速度和加速度系统
- 边界限制
- 自动射击系统
- 生命值和无敌机制

✅ **武器系统**
- 武器基类架构

✅ **子弹系统**

## 本地开发与 P0 修复（2026-11-10）

当前修复版本位于 `fix/p0-gameplay-stability` 分支。保持原来的 Canvas 2D 引擎，已修复第一波刷怪、关卡难度累乘、Boss 受击与敌方弹幕、Boss 动画秒/毫秒混用、Boss 击败后重复生成、结算回调和暂停后重置关卡等问题。画布现会按浏览器窗口等比例缩放。

Windows / macOS / Linux 均可使用 Node.js 直接运行：

```bash
npm install
npm run dev
# 浏览器打开 http://127.0.0.1:8080
```

执行全部回归测试：

```bash
npm run test:all
```

测试拆分为：`npm test`（基础与游戏状态）、`npm run test:phase3`（关卡/Boss/道具）和 `npm run test:p0`（本次回归）。测试数以实际执行输出为准。

目前依然只是射击游戏核心框架，尚无 2018 年后《全民飞机大战》的战机图鉴、装备套装、双宠物与存档系统。这些功能将在后续二创阶段开发。

## 操作说明

### 键盘控制
- **Enter** - 开始游戏（在菜单界面）
- **方向键/WASD** - 控制战机移动
- **ESC** - 暂停/继续游戏
- **F3** - 切换调试模式（显示性能信息）

### 游戏状态
- **菜单** - 按 Enter 开始游戏
- **游戏中** - 控制战机躲避和射击
- **暂停** - 按 ESC 暂停/继续
- **游戏结束** - 按 Enter 返回菜单
