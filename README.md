# 飞机大战 · 圆梦计划

> 一款浏览器怀旧竖版射击游戏：**自由选择战机、穿满级装备、带双宠物出战，金币钻石无限抽。**

基于现有的 Canvas 2D 飞机射击框架继续开发，加入战机仓库、神犬/天蓬套装、宠物、免费抽奖和专属战斗技能。目标是体验当年没能拥有的装备与宠物，而不是复刻商业运营系统。

**非官方同人练习项目。** 名称用于怀旧主题；技能、数值、抽奖概率和大部分新增外观是本项目自行设计，不代表《全民飞机大战》官方设定。本项目不提供官方账号、充值或可提现奖励，不应把未经许可的原版游戏图片或音乐上传到仓库。

## 快速开始

需要 Node.js（建议 **18+**；在 Node.js 22 下完成测试）。本项目不需要后端数据库。

```bash
git clone https://github.com/zsc/plane_shooter_svg_game.git
cd plane_shooter_svg_game
npm run dev
```

打开 **http://127.0.0.1:8080** 即可游玩。

- 大厅选择一架战机，点击「开始游戏」。
- 想直接体验顶级装备：进入「装备仓库」，点击「圆梦：全部解锁满级」；可切换神犬套或天蓬套。
- 想体验满级双宠：进入「双宠出战」，点击「全部宠物满级解锁」。
- 想保留抽奖的惊喜：到「装备抽奖」或「宠物抽奖」中免费单抽、十连。
- 游戏提供静音控制；调试时建议先静音。

（建议使用本地服务器访问。GitHub 仓库保存的是源码；要提供公网试玩链接，需要另行部署 GitHub Pages 等静态网站服务。）

## 操作说明

| 功能 | 按键 / 控件 |
| --- | --- |
| 移动战机 | 方向键、WASD，支持鼠标与触摸输入 |
| 普通攻击 | 自动开火 |
| **战机主动技能** | **Q** / 画面右下角按钮 |
| **装备主武器技能** | **E** / 画面左下角按钮 |
| 炸弹 | **空格** |
| 切换副武器 | **Tab** |
| 暂停 / 恢复 | **Esc** / 暂停按钮 |
| 更换战机/装备/宠物 | 回到大厅对应的仓库页面 |
| 调试信息 | **F3** |

**Q 与 E 独立冷却。** 副炮和部分核心会自动发动，护甲在受击时生效；没有装备对应主武器时，E 按钮不可用。

## 无限抽奖与保底

| 物品类型 | 奖池 | 普通 / 稀有 | 史诗 | 传说 |
| --- | --- | ---: | ---: | ---: |
| 装备 | 金币补给 | 70% | 27% | 3% |
| 装备 | 钻石祈愿 | 55% | 35% | 10% |
| 宠物 | 金币召唤 | 70% | 27% | 3% |
| 宠物 | 钻石召唤 | 55% | 35% | 10% |

- 单抽与十连均免费；奖励逐一揭晓，可跳过动画。
- 各奖池按自己的抽数计算保底：**最多 10 抽获得史诗及以上、最多 30 抽获得传说**。
- 抽到指定品质重置对应计数；重复物品会累计持有份数，不删除已有强化等级。
- 没有真实货币、账号充值、可提现物品或支付入口。

**概率和保底规则均为本项目自行设计，不是原版官方抽奖概率。**

## 本地存档

浏览器 `localStorage` 保存的内容如下：

| 键 | 内容 |
| --- | --- |
| `plane-dream-gear-v1` | 装备库存、强化等级、穿戴、各装备奖池保底与抽数 |
| `plane-dream-pets-v1` | 宠物库存、等级、左右出战位、各宠物奖池保底与抽数 |

存档只保存在当前浏览器/域名下；清除网站数据、更换浏览器或使用隐私模式可能导致记录丢失。战斗中的临时冷却不保存；**没有云存档和跨设备同步**。
